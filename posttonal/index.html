How Forte's method picks the prime form

Normal order: arrange the pitch classes in ascending order and try every rotation. Keep the one with the smallest interval from first to last. If two rotations tie, compare the interval from first to second, then first to third, and so on. The smallest wins. This packs the set toward the left.

Prime form: find the normal order of the set and of its inversion, transpose each to start on 0, and keep the one that is better packed by the same rule.

Rahn's method (used by many newer textbooks) breaks ties by working from the right, comparing first to second-to-last. The two methods give different prime forms for six set classes, marked ≠ Rahn in the table: 5-20, 6-Z29, 6-31, 7-Z18, 7-20 and 8-26. This app always uses Forte's answer.
